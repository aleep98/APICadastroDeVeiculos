# API Cadastro de Veículos

API REST simples para gerenciar veículos e usuários.

## Rápido
1. npm install
2. crie um arquivo .env e ajuste as variáveis de ambiente:MONGODB_URI
3. npm start (ou npm run dev)

Base: http://localhost:3000
Endpoints: /veiculos, /users (GET/POST/PUT/DELETE)

Tecnologias: Node.js, Express, MongoDB

Contribuições: PRs são bem-vindas.
